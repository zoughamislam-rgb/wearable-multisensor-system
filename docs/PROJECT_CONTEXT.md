# Project Context

This project develops an ESP32-based multi-sensor wearable platform for measuring physiological and motion-related signals.

The goal is not simply to combine commercial modules, but to use the project as an embedded-electronics and sensor-system learning platform relevant to a nanoelectronics student.

Planned measurements include heart rate, SpO2, temperature, motion, and potentially hydration or other useful physiological parameters.

For every measurement, the project studies:
- sensing principle,
- appropriate sensor,
- body placement,
- signal type,
- sampling rate,
- communication interface,
- analog front-end requirements,
- power requirements,
- signal processing,
- and integration with the ESP32.

Development should progress from a Master Sensor Map -> component selection -> individual sensor experiments -> integrated prototype -> data acquisition -> application/dashboard.

The public repository should document experiments, firmware, electronics, measurements, design decisions, and engineering lessons rather than presenting unfinished ideas as completed results.
